# Arte original dos fundos

`mundo_1.png` … `mundo_4.png` e `secreto.png` são a arte-fonte (um fundo por mundo + a sala secreta).
Os ficheiros `mundo*_n*.webp`, `map-mundo*.webp` e `sala_secreta.webp` da pasta principal derivam destas imagens:
redimensionadas para 1280×720 e, dentro de cada mundo, com variações de luz (tarde, entardecer, noite, madrugada)
para os níveis não ficarem todos iguais. Para trocar a arte, substitui estes PNG e volta a exportar com as mesmas
variações (ver o script de exportação descrito no README) ou, mais simples, substitui diretamente os `.webp`
(1280×720) mantendo os mesmos nomes de ficheiro.
